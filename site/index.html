Backend tests (Python)

Test reports for lana-20/backend-tests-py: GraphQL, SQL on four engines, MongoDB, DynamoDB Local, the Firestore emulator, Redis, and Linux over SSH, each against a real, disposable dependency. Published by CI on every push to main.

Allure reportEvery CI job merged into one report, grouped by section, and by engine for SQL. CI runsOne job per section, one per SQL engine.
SectionWhat it checks
GraphQLStrawberry on FastAPI over HTTP: auth per field, errors next to partial data, cursor pagination, depth and alias limits, N+1 query counts, schema breaking-change gate.
SQLPostgreSQL, MySQL, SQL Server and SQLite: migrations, constraints, locking, isolation, and engine differences written down as tests.
MongoDBReplica set: validators, index use via explain(), TTL, aggregation, transactions, change streams.
DynamoDB LocalConditional writes, optimistic locking, query vs scan, GSI, pagination, TTL filtering.
Firestore emulatorCRUD, a composite query, a transaction, security rules tested as end users.
RedisCache-aside: hits, misses, TTLs, invalidation on update.
Linux over SSHProcesses, ports, health, permissions, logs, headroom, supervised restart, cron and logrotate; plus Bats tests for the healthcheck script.
